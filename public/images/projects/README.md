# Project screenshots

Drop REAL screenshots of your projects here, then set the matching
`screenshot` field in `src/lib/content.ts`, for example:

```ts
screenshot: "/images/projects/skyreserve.png",
```

Until then the site shows a clearly labeled "Screenshot placeholder".

Tips:
- Use real captures of the running app only. Never mockups presented as screenshots.
- Aim for 16:10, about 1280×800, PNG or JPG.
- Check that no private data (emails, phone numbers, tokens) is visible in the shot.
